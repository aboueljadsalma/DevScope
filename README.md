# 🚀 DevScope

### Plateforme de recherche et de gestion de candidats développeurs

## 📌 Présentation du projet

**DevScope** est une application web conçue pour faciliter le processus de recrutement dans le domaine informatique.

Elle permet aux recruteurs de rechercher des développeurs à partir de leur nom d'utilisateur GitHub, de consulter leurs profils ainsi que leurs dépôts publics, et de gérer une liste de candidats présélectionnés (*Shortlist*).

L'application exploite l'API GitHub pour récupérer les informations des développeurs et MockAPI pour assurer la gestion des candidats.

## 🎯 Objectifs

- Simplifier la recherche de profils techniques.
- Consulter les informations publiques des développeurs.
- Explorer les dépôts GitHub des candidats.
- Ajouter et gérer des candidats dans une shortlist.
- Faciliter la présélection des profils.

## 🛠️ Technologies utilisées

- HTML5
- Tailwind CSS
- JavaScript (ES6 Modules)
- Git & GitHub
- GitHub API
- MockAPI

## ⚙️ Fonctionnalités principales

1. **Recherche :** rechercher un développeur à partir de son nom d'utilisateur GitHub.
2. **Profil :** afficher les informations du développeur et ses dépôts publics.
3. **Shortlist :** ajouter et gérer les candidats présélectionnés.

## 👩‍💻 Réalisation

Projet réalisé dans le cadre d'un travail pratique de développement web, avec une approche basée sur la modularité JavaScript et l'intégration d'API externes.
